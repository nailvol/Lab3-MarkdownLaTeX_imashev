## Введение
Markdown - это лёгкий язык разметки для быстрого форматирования текста. Он легко преобразуется в HTML и используется для создания документации, заметок, README-файлов и веб-контента, позволяя сосредоточиться на тексте, а не на сложном коде.

---

## Основные возможности Markdown
Основные возможности Markdown - это простое оформление заголовков, списков, ссылок, выделения текста и блоков кода. Синтаксис использует обычные символы вместо громоздких тегов, что делает документ понятным даже в исходном виде.

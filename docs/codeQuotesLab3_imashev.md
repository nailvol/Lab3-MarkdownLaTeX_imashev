## Пример команды Git (inline-код)

Для проверки состояния файлов в репозитории используется команда `git status`.

## Блок кода с указанием языка (C#)

```csharp
using System;

class Program
{
    static void Main()

        Console.WriteLine("Hello, Markdown!");

```

## Блок кода без указания языка

```
git init
git add .
git commit -m "Initial commit"
git push
```
